# 🤖 AI & ML Mini Projects

A collection of hands-on Artificial Intelligence, Machine Learning, and Natural Language Processing (NLP) projects built to develop practical skills in Python, data analysis, and machine learning.

This repository contains mini-projects focused on solving real-world problems using data-driven approaches.

## 📂 Projects

### 1. Customer Churn Prediction

**Objective:** Explore customer data to understand and predict customer churn — when customers stop using a service.

- Analyze customer data to identify useful patterns.
- Explore features that may influence customer retention.
- Develop a machine learning classification workflow.
- Evaluate model performance using appropriate metrics.

**Key Concepts:** Machine Learning, Classification, Data Preprocessing, Exploratory Data Analysis (EDA)

**Dataset:** Telco Customer Churn dataset

**Project Folder:** `Customer-Churn-Prediction/`

### 2. Customer Service NLP

**Objective:** Explore Natural Language Processing techniques for analyzing customer service messages and requests.

- Work with text-based customer service data.
- Explore text preprocessing and cleaning techniques.
- Investigate patterns in customer queries and service requests.
- Build a foundation for NLP-based customer service applications.

**Key Concepts:** Natural Language Processing (NLP), Text Preprocessing, Text Analysis, Python

**Dataset:** Bitext Customer Service dataset

**Project Folder:** `Customer-Service-NLP/`

## ⚙️ Getting Started

### Prerequisites

- Python 3.10 or a compatible version
- pip (Python package manager)
- Visual Studio Code or another Python IDE

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/muskancodehub11/AI-ML-Mini-Projects.git
```

**2. Navigate to the project directory**

```bash
cd AI-ML-Mini-Projects
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate the virtual environment**

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

**5. Install the required libraries**

Install the dependencies needed by the particular project. For example:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

Install additional NLP libraries only if they are required by your code.

### Run the Projects

For Customer Churn Prediction:

```bash
python Customer-Churn-Prediction/test.py
```

For Customer Service NLP:

```bash
python Customer-Service-NLP/bit.py
```

*These commands assume the scripts are runnable from the repository root. Adjust them if your code uses different entry points or file paths.*
